Building a health supplement brand's own online store, I built the commerce core (cart, orders, payment, admin) on my own and integrated the Naver Pay order API.

브랜드사가 자체 쇼핑몰을 정해진 일정 안에 열어야 했고, 주문·결제·관리자 같은 표준 기능을 브랜드에 맞게 갖춰야 했습니다.The brand needed its own store open on a fixed schedule, with standard order, payment and admin features fitted to the brand.

장바구니, 배송지, 주문·결제, 교환·반품·환불, 관리자 페이지를 단독으로 구현하고 네이버페이 주문형 API를 연동했습니다.I built the cart, shipping addresses, orders and payment, exchanges, returns and refunds, and the admin pages on my own, and integrated the Naver Pay order API.

10개월 계획 일정에 맞춰 오픈, 월 약 2,000건 주문 처리.Opened on the 10-month plan, handling about 2,000 orders a month.

What I did

커머스 코어 단독 구현Commerce core, built on my own
장바구니, 배송지, 주문·결제, 교환·반품·환불 클레임, 관리자 페이지를 혼자 구현했습니다.I built the cart, shipping addresses, orders and payment, exchange, return and refund claims, and the admin pages myself.
네이버페이 주문형 API 연동Naver Pay order API
네이버페이 주문을 쇼핑몰 주문으로 받아 오도록 연동했습니다. 변경된 주문을 조회하는 API를 Cron으로 주기적으로 불러 자사몰 주문으로 만들고, 상품 주문 번호에 유니크 키를 걸어 같은 주문이 두 번 들어오지 않게 했습니다. 재고는 결제가 끝난 시점에 줄이고, 취소와 반품 상태도 같은 폴링으로 반영했습니다.I integrated the API so Naver Pay orders arrive as store orders. A cron job polls the changed-orders API and creates store orders, and a unique key on the product order number keeps an order from arriving twice. Stock is reduced once payment completes, and cancellations and returns come in through the same polling.
관리자 검색 고도화Admin search
운영자가 쓰는 관리자 페이지의 검색 기능을 고도화했습니다.I improved search in the admin pages operators use.
SNS 간편 로그인과 회원가입Social login and sign-up
SNS 계정으로 가입하고 로그인하는 기능을 개발했습니다.I built sign-up and login with social accounts.
운영 자동화Operations automation
반복되는 운영 작업은 Linux Cron으로 돌리고, Jenkins로 배포했습니다.Recurring operations work runs on Linux cron, and deploys go through Jenkins.

Result

1년 차에 FOLDER MALL 운영과 병행하며 커머스 코어를 혼자 구현해, 10개월 계획 일정에 맞춰 쇼핑몰을 열었습니다.

In my first year, alongside running FOLDER MALL, I built the commerce core myself and the store opened on its 10-month plan.
